# TuristeaYa

Proyecto integrado con aplicación Expo y backend FastAPI. Expo es el único frontend mantenido y también se puede exportar a web.

Consulta `outputs/CONTEXTO_TURISTEAYA.md` y `outputs/REVISION_SISTEMA.md` para configuración, pruebas y pendientes.

Para Expo Go ejecuta `./outputs/INICIAR_EXPO_GO.ps1` o, desde `outputs/TuristeaYa-Expo`, `npm run go`. El frontend usa la API de Render por defecto.
